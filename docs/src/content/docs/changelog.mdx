Packages are released independently with [Changesets](https://github.com/changesets/changesets). The newest version of each is shown next to its name. Update related packages together; for example, `@atmyapp/astro` expects the matching `@atmyapp/core`.

```sh
npm install @atmyapp/astro@latest @atmyapp/core@latest @atmyapp/structure@latest
npm install --save-dev @atmyapp/cli@latest
```

Breaking changes are called out in the notes. Before `1.0`, a minor version (`0.5` → `0.6`) may include them.
