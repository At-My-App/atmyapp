# AtMyApp documentation

Developer documentation for the SDKs in this repository. The navigation is defined in `astro.config.mjs`; the shell renders that same tree so pages are not hidden behind a separate hand-maintained menu.

## Run locally

```sh
pnpm --filter @atmyapp/docs dev
pnpm --filter @atmyapp/docs build
pnpm --filter @atmyapp/docs preview
```

Search results are generated by Pagefind during a production build. Use build plus preview to test search; the dev server deliberately shows Starlight's development notice. Keep exactly one Search component per page, in the header: multiple instances create duplicate result IDs and competing keyboard handlers.

The build runs Astro checks, generates pages and the search index, then validates local links and unique search markup. For visual changes, also verify desktop/mobile navigation, light/dark themes, search results, Ctrl/Cmd+K, and Escape in a browser.

## Content conventions

- Lead with the developer task and show a complete setup before isolated API snippets.
- Verify examples against the SDK source, including defaults and runtime validation restrictions.
- Distinguish public website keys, CLI tokens, and per-request preview keys.
- Explain build-time versus runtime reads and static-site publication delays.
- Put each field option in the field reference; link from conceptual guides.
- Keep existing routes when reorganizing navigation so bookmarks remain useful.

## Deploy

The Deploy Docs workflow builds this package and uploads the entire `dist` directory to GitHub Pages. Include `_astro` and `pagefind` assets from the same build as the HTML. Documentation-only changes do not require an npm changeset.
