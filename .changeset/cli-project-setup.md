Project setup from the CLI: `code connect github` (one browser step) and `code repos|add|ls|sync|rm`; `projects website connect` for the first website with the repository's suggested settings; `hosting websites|presets`, `env`, `secrets` (values from stdin or an environment variable, never a flag) and `preview create|edit`; `locales add|rm|default|jobs`, `settings images|seo` and `collections edit`; and `forms ls|create|edit|rm|layout` with `forms captcha verify`.
